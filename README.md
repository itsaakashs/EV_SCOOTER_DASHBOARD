# Petrol vs EV Two-Wheeler Sales Trend Analysis

This project analyzes the EV scooter market using Power BI through a 3-page interactive dashboard with navigation. It provides insights into state-wise, brand-wise, and monthly sales trends to understand market performance. Variant-level analysis highlights average pricing and keyless scooter adoption using KPI and tooltip visuals. A comparison between EV and petrol scooters reveals sales and revenue growth patterns. The dashboard supports data-driven business decisions through KPIs like MoM %, YoY %, total sales, and top-selling brands.

## Tools Used
- Microsoft Excel

- Microsoft Power BI Desktop

- Power Query Editor

- DAX (Data Analysis Expressions)
## Dataset Description

Excel file name - "EV Details.xlsx"
## Installation

Step 1: Download the Dataset

- Download the Excel dataset (.EV Details.xlsx) to your local system.

- Save it in a dedicated project folder.
Step 2: Install Power BI

- Download Microsoft Power BI Desktop from:

- Microsoft Store or

- Official Microsoft website

- Install and open Power BI Desktop.
Step 3: Load Data into Power BI

- Open Power BI Desktop

- Click Get Data → Excel

- Select the downloaded Excel file

- Load the data into Power BI
